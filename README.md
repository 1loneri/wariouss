# wariouss.vp

Архив попыток сайта **wariouss.vp** и текущая функциональная версия.

- `attempts/` — предыдущие HTML/ZIP-версии и варианты дизайна.
- `current-project/` — текущий Node/Express/PostgreSQL проект.
- `wariouss-vp-all-attempts.zip` — полный архив найденных попыток.

Секреты (`.env`, Twitch Client Secret, SESSION_SECRET и пароли БД) намеренно не загружаются.
