# Старые HTML-версии

Здесь хранятся/будут храниться отдельные версии интерфейса `wariouss.vp`.

Порядок версий:
- `01_source/` — исходная версия
- `02_redesign/` — redesign
- `03_no_w/` — вариант без W
- `04_watch_earn/` — вариант с просмотром/начислением
- `05_bold/` — bold-типографика
- `06_bold_small_text/` — bold + уменьшенный текст
- `07_latest/` — последняя HTML-версия до полноценного Node-проекта

Файлы в этих папках — исторические версии и не должны использоваться вместо `current-project/` без проверки.
