# Current functional project

Актуальная функциональная версия `wariouss.vp`:

- `public/index.html` — пользовательский сайт
- `public/admin.html` — админ-панель
- `server.js` — Node/Express backend
- `sql/schema.sql` — PostgreSQL schema
- `.env.example` — пример переменных окружения без секретов

Важно: `.env` с Twitch Client Secret, SESSION_SECRET и паролем БД в GitHub не добавлять.
